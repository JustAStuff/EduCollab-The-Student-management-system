## Team Lead Task Management

### Overview
Team Leads can now manage their own tasks using the same workflow as team members, including task execution, submission, and peer review.

### Accessing TL Tasks

1. **Navigate to WorkspaceTL Page**
   - Click on your workspace from the dashboard
   - Select the "Team Lead" view
   - Look for the "My Tasks" section at the top

2. **View Task Status**
   - Tasks are displayed with color-coded status badges:
     - **Gray**: To Do (not started)
     - **Orange**: In Progress (actively working)
     - **Blue**: Under Review (submitted, awaiting review)
     - **Red**: Needs Revision (requires changes)
     - **Green**: Completed (approved)

### Starting a Task

1. **Locate the Task**
   - Find your assigned task in the "My Tasks" section
   - Task must have "To Do" status

2. **Start Working**
   - Click the "Start Task" button
   - Task status changes to "In Progress"
   - You can now work on the task

### Submitting Work

1. **Upload Your Submission**
   - Click "Upload Result" button on an in-progress task
   - Select your file (max 10MB)
   - Supported formats: PDF, DOC, DOCX, TXT, images, etc.
   - Click "Submit"

2. **Submission Confirmation**
   - Task status changes to "Under Review"
   - File is uploaded to secure storage
   - Workspace members are notified for review

### Handling Review Feedback

1. **Approved Tasks**
   - Task status changes to "Completed"
   - No further action required
   - Task appears in completed section

2. **Revision Requests**
   - Task status changes to "Needs Revision"
   - Review comments are displayed
   - Task returns to "In Progress" status
   - You can re-submit updated work

---## S
ubmission Modification Process

### Overview
Team members can modify their submissions before final approval, allowing for corrections without TL intervention.

### When You Can Modify Submissions

- **Task Status**: Must be "Under Review"
- **Your Task**: Only modify your own submissions
- **Before Approval**: Cannot modify after task is completed

### Deleting a Submission

1. **Access Your Task**
   - Go to WorkspaceTM page
   - Find your task with "Under Review" status

2. **Delete Process**
   - Click "Delete Submission" button
   - Confirm deletion in the dialog
   - File is permanently removed from storage
   - Task status returns to "In Progress"

3. **After Deletion**
   - You can upload a new submission
   - Previous file is completely removed
   - No trace of old submission remains

### Re-uploading a Submission

1. **Access Re-upload Option**
   - Find your task with "Under Review" status
   - Click "Re-upload Submission" button

2. **Replace File**
   - Select new file to upload
   - Old file is automatically replaced
   - Task remains in "Under Review" status

3. **Confirmation**
   - New file replaces the previous one
   - Reviewers see the updated submission
   - Upload timestamp is updated

### Best Practices

- **Review Before Submitting**: Check your work thoroughly before initial submission
- **Quick Corrections**: Use re-upload for minor corrections
- **Major Changes**: Use delete and re-submit for significant revisions
- **File Naming**: Use descriptive filenames for clarity

## Peer Review System

### Overview
All workspace members can review and approve submissions from Team Leads, ensuring accountability and quality control.

### Who Can Review

- **Any Workspace Member**: All members can review TL submissions
- **Excluding Submitter**: Cannot review your own submissions
- **Multiple Reviewers**: Multiple people can review the same task

### Review Process

1. **Finding Tasks to Review**
   - Look for tasks with "Under Review" status
   - Check the "Team Members" section in WorkspaceTL
   - Review notifications appear in your dashboard

2. **Reviewing a Submission**
   - Click on the task with submitted work
   - View/download the submitted file
   - Examine the work quality and completeness

3. **Making a Decision**
   - **Approve**: If work meets requirements
   - **Request Redo**: If work needs improvement

### Approving Work

1. **Review the Submission**
   - Download and examine the file
   - Verify it meets task requirements
   - Check for quality and completeness

2. **Approve Process**
   - Click "Approve" button
   - Task status changes to "Completed"
   - Submitter is notified of approval
   - Task moves to completed section

### Requesting Revisions

1. **Identify Issues**
   - Note specific problems or missing elements
   - Consider what improvements are needed

2. **Request Redo Process**
   - Click "Request Redo" button
   - Enter detailed feedback in comments field
   - Explain what needs to be changed
   - Submit the review

3. **After Requesting Redo**
   - Task status changes to "Needs Revision"
   - Submitter sees your feedback
   - Task returns to "In Progress"
   - Submitter can re-submit improved work

### Review Guidelines

- **Be Constructive**: Provide helpful, specific feedback
- **Be Timely**: Review submissions promptly
- **Be Fair**: Apply consistent standards
- **Be Detailed**: Explain what needs improvement

---## T
ask Revocation Process

### Overview
Team Leads can revoke task assignments from members when reassignment is needed, while preserving any completed work.

### When to Revoke Tasks

- **Reassignment Needed**: Member unavailable or overloaded
- **Priority Changes**: Task needs different expertise
- **Workflow Issues**: Task blocking other work
- **Resource Reallocation**: Balancing workload

### Revocation Process

1. **Access Task Management**
   - Go to WorkspaceTL page
   - Find the "Team Members" section
   - Locate the assigned task

2. **Initiate Revocation**
   - Click "Revoke Assignment" button next to the task
   - Confirmation dialog appears

3. **Confirm Revocation**
   - Review task details in dialog
   - Confirm member name and task title
   - Click "Confirm Revocation" to proceed
   - Click "Cancel" to abort

4. **After Revocation**
   - Task becomes unassigned
   - Task appears in available tasks pool
   - Previous work/submissions are preserved
   - Member is notified of revocation

### What Happens to Work

- **In Progress Tasks**: Work status preserved for reference
- **Submitted Tasks**: Submissions remain accessible
- **Completed Tasks**: Cannot be revoked
- **History**: All progress history maintained

### Reassignment After Revocation

1. **Task Becomes Available**
   - Revoked task appears in unassigned tasks
   - Can be assigned to any workspace member
   - Previous progress visible to new assignee

2. **Assigning to New Member**
   - Use normal task assignment process
   - New member sees task history
   - Can continue from where previous member left off

### Best Practices

- **Communicate First**: Discuss with member before revoking
- **Document Reasons**: Note why revocation was necessary
- **Preserve Work**: Ensure important progress isn't lost
- **Quick Reassignment**: Reassign promptly to avoid delays

## Submissions Gallery

### Overview
The submissions gallery in WorkspaceDashboard provides a centralized view of all task submissions across the workspace.

### Accessing the Gallery

1. **Navigate to Dashboard**
   - Go to WorkspaceDashboard
   - Scroll to "Workspace Submissions" section
   - Gallery displays all submitted files

2. **Gallery Layout**
   - Grid view of all submissions
   - File icons based on type
   - Submitter name and task title
   - Submission date and status

### Viewing Submissions

1. **File Information**
   - **Submitter**: Who uploaded the file
   - **Task**: Which task the submission belongs to
   - **Date**: When it was submitted
   - **Status**: Current review status
   - **File Type**: Format and size information

2. **File Actions**
   - **View**: Preview supported file types in browser
   - **Download**: Save file to your device
   - **Details**: See full task and submission information

### Supported File Types

#### Viewable in Browser
- **Images**: JPG, PNG, GIF, SVG
- **Documents**: PDF
- **Text**: TXT, MD
- **Code**: JS, HTML, CSS, JSON

#### Download Only
- **Office**: DOC, DOCX, XLS, XLSX, PPT, PPTX
- **Archives**: ZIP, RAR
- **Other**: Any file type not listed above

### Gallery Features

1. **Real-time Updates**
   - New submissions appear automatically
   - Status changes update in real-time
   - No page refresh needed

2. **Search and Filter**
   - Search by submitter name
   - Filter by task status
   - Sort by submission date

3. **Bulk Operations**
   - Download multiple files
   - Export submission list
   - Generate reports

### Privacy and Access

- **Workspace Members**: Can view all submissions
- **External Users**: No access to submissions
- **File Security**: All downloads are logged
- **Permission Checks**: Access verified on each request

---## Task 
Status Reference

### Status Definitions

| Status | Color | Description | Available Actions |
|--------|-------|-------------|-------------------|
| **To Do** | Gray | Task not started | Start Task |
| **In Progress** | Orange | Actively working on task | Upload Result |
| **Under Review** | Blue | Submitted, awaiting review | Delete/Re-upload (submitter), Approve/Redo (reviewers) |
| **Needs Revision** | Red | Requires changes based on feedback | Re-submit work |
| **Completed** | Green | Approved and finished | View only |

### Status Transitions

```
To Do → In Progress → Under Review → Completed
                           ↓
                    Needs Revision
                           ↓
                    In Progress (re-submit)
```

### Action Permissions

| Action | Team Lead | Team Member | Reviewer |
|--------|-----------|-------------|----------|
| Start Task | ✓ (own tasks) | ✓ (assigned tasks) | ✗ |
| Upload Submission | ✓ | ✓ | ✗ |
| Delete Submission | ✓ (own) | ✓ (own) | ✗ |
| Re-upload Submission | ✓ (own) | ✓ (own) | ✗ |
| Approve Task | ✗ (own tasks) | ✓ (others' tasks) | ✓ |
| Request Redo | ✗ (own tasks) | ✓ (others' tasks) | ✓ |
| Revoke Assignment | ✓ | ✗ | ✗ |

## Troubleshooting

### Common Issues

#### Cannot Start Task
**Problem**: "Start Task" button is disabled or missing
**Solutions**:
- Verify task is assigned to you
- Check task status is "To Do"
- Refresh the page
- Contact workspace admin if issue persists

#### Upload Fails
**Problem**: File upload doesn't work or shows error
**Solutions**:
- Check file size (must be under 10MB)
- Verify file type is supported
- Check internet connection
- Try a different file format
- Clear browser cache

#### Cannot Modify Submission
**Problem**: Delete/Re-upload buttons not visible
**Solutions**:
- Verify task status is "Under Review"
- Confirm it's your own task
- Check you haven't been removed from workspace
- Refresh the page

#### Review Options Missing
**Problem**: Cannot approve or request redo
**Solutions**:
- Verify you're not reviewing your own task
- Check you're a workspace member
- Confirm task has a submission
- Refresh the page

#### Submissions Not Visible
**Problem**: Gallery is empty or missing submissions
**Solutions**:
- Verify you're a workspace member
- Check if any tasks have been submitted
- Refresh the page
- Check browser permissions for file access

### Getting Help

1. **Check Status**: Verify your workspace membership
2. **Refresh Page**: Many issues resolve with a page refresh
3. **Clear Cache**: Clear browser cache and cookies
4. **Contact Admin**: Reach out to workspace Team Lead
5. **Technical Support**: Contact system administrator

### Error Messages

| Error | Meaning | Solution |
|-------|---------|----------|
| "File too large" | File exceeds 10MB limit | Compress or split file |
| "Unsupported file type" | File format not allowed | Convert to supported format |
| "Permission denied" | Insufficient access rights | Contact workspace admin |
| "Task not found" | Task may have been deleted | Refresh page, contact admin |
| "Upload failed" | Network or server issue | Try again, check connection |
