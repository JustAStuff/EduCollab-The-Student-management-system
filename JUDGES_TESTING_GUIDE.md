## 🎯 What to Test

### 1. Dashboard & Analytics (2 minutes)
1. Login with either test account
2. View personal statistics dashboard
3. Check completion rates, efficiency metrics
4. See achievement badges and streaks
5. View productivity trend chart

### 2. Workspace Management (3 minutes)
**As Team Leader:**
1. Create a new workspace
2. Add tasks with descriptions and deadlines
3. View workspace dashboard (shows workspace details like name, team mambers and their task details, quick task creation task bar where any user can create and assign tasks)
4. Check team member list

**As Team Member:**
1. View assigned tasks
2. See task details and requirements
3. Check workspace participation stats

### 3. Task Workflow (5 minutes)
**As Team Member:**
1. Select a task
2. Upload a file submission
3. Add submission notes
4. Submit work

**As Team Leader:**
1. View submitted work
2. Download submission files
3. Review and provide feedback
4. Approve or request changes

### 4. Real-time Features (2 minutes)
1. Open public chat
2. Send messages
3. See online users list
4. Check notification badges

### 5. Problem Statements (2 minutes)
1. Navigate to Problem Statements
2. View available problems
3. Create or join a team
4. Collaborate on solutions
